Original CSV/JSONL files are immutable evidence: generation refuses changed content under the same dataset identity, and a batch ID hashes canonical configuration, batch sequence and source-file hashes. Validation assigns every input row exactly one disposition without rewriting its source; invalid payloads remain in raw storage with rejection reasons elsewhere. Replaying a successful batch is a no-op, while failed attempts remain auditable and can be retried. Raw lake Parquet is a normalised representation of those files, not their byte-identical replacement; see the [contracts](../data_contracts.md) and [quality report](../data_quality_report.md).
